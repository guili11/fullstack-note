# 锁核心极简背诵版
1. **核心作用**：管控并发操作执行，规避资源竞争错乱
2. **常见类型**
    - 互斥锁：同一时间仅允许一个线程执行操作
    - 读写锁：读可并发、写互斥，兼顾性能与数据安全
3. **关键风险**：谨防死锁，避免线程互相阻塞无法释放资源
4. **场景区分**
    - 本地锁：单机进程内并发控制
    - 分布式锁：多服务集群间并发管控
