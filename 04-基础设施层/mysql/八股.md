# MySQL 八股文核心问题（纯题目版）

MySQL 最核心解决两大问题：**并发安全**和**查询加速**。

- **并发安全**：多个事务同时操作数据不乱套。通过 **锁 + MVCC** 实现隔离级别，让读写能并发执行，同时保证数据一致性。
- **查询加速**：海量数据中快速找到目标。通过 **B+ 树索引** 减少扫描行数，利用索引的天然有序性省去额外排序。**本质是减少磁盘 IO**（B+ 树矮减少随机 IO、覆盖索引减少回表 IO、有序性减少排序 IO）。

底层靠 **三大日志**（redo log 保持久、undo log 保原子/MVCC、binlog 保复制）支撑可靠性。
面试所有八股问题，最终都回归到这两个核心目标上。
