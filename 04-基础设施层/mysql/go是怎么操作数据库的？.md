# 纯文字新手版：一次 SQL 执行完整流程
**基础前提**：程序启动时，会提前创建**数据库连接池**（核心作用：支持高并发），连接池里提前维护好了多个 TCP 长连接，多个请求可以同时复用这些连接，不用反复新建/销毁。

---

## 一次 SQL 执行的 5 个步骤（纯文字）
1. **申请连接**
业务代码要操作数据库时，先从连接池里**借用一个空闲的长连接**。

2. **预约归还**
用 `defer` 做兜底约定：不管后续代码正常执行还是报错，等当前函数结束时，**自动把连接还回连接池**。

3. **发送 SQL**
通过借到的这个长连接，把要执行的 SQL 语句（比如查询用户、新增数据）发送给数据库服务器。

4. **获取结果**
数据库执行完 SQL 后，把结果（查询到的数据、操作是否成功）通过长连接返回给程序。

5. **归还连接**
函数执行完毕，`defer` 自动触发，将连接归还到连接池，连接恢复空闲状态，给下一个请求使用。

总结：两个defer
1. 临时连接归还 （gorm自动完成，没有gorm的需要defer close）
2. 主连接归还 （os自动，但是可以优雅关闭）
