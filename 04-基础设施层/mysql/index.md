# MySQL 序章 — 从需求出发梳理知识

## MySQL 本质

MySQL 是一个关系型数据库管理系统（RDBMS），核心目标是：

- **安全、高效、可靠地存储和读取业务数据**
- 处理业务发展过程中遇到的各种问题

***

## 数据库要解决的核心问题(需求)  后续具体node，进入解决需求， 

随着业务发展，一个数据库要面对的问题大致可以分为以下几类：

### 1. 数据存储（CRUD）

**问题：** 用户注册、信息写入，如何把数据存起来？\
**产生的知识模块：**

- 表结构设计
- 字段类型选择
- DDL（CREATE / ALTER / DROP）
- INSERT / UPDATE / DELETE

***

### 2. 数据查询

**问题：** 如何查到需要的数据？\
**产生的知识模块：**

- SELECT 查询
- WHERE 条件
- ORDER BY / GROUP BY
- JOIN / 子查询 / 聚合函数

***

### 3. 查询性能

**问题：** 数据量大后，查询越来越慢\
**产生的知识模块：**

- 索引设计（单列索引 / 联合索引 / 覆盖索引）
- B+ 树结构
- EXPLAIN 分析查询计划
- SQL 优化技巧（避免全表扫描、优化排序和分页）

***

### 4. 数据正确性（并发安全）

**问题：** 多人同时修改数据，可能导致数据不一致\
**产生的知识模块：**

- 事务管理
- ACID 原则
- 隔离级别
- 锁机制（行锁、表锁、意向锁）
- MVCC（多版本并发控制）

***

### 5. 数据可靠性（持久化）

**问题：** 数据库崩溃或服务器断电，数据不能丢\
**产生的知识模块：**

- Redo Log
- Undo Log
- Binlog
- 备份与恢复策略

***

### 6. 系统扩展（可扩展性）

**问题：** 业务继续增长，单机数据库压力大\
**产生的知识模块：**

- 主从复制
- 读写分离
- 分库分表
- 高可用架构设计

***
