今天重点理解的概念

---

1. Tool Calling（核心）

理解：

LLM 不是真的执行工具
它只是：
“决定调用哪个 tool”

流程：

用户问题
→ LLM分析
→ 返回tool调用参数
→ 后端执行tool
→ 结果返回LLM
→ LLM生成最终回答

---

2. Workflow / State

理解：

Agent 不只是聊天
而是：
状态驱动工作流

比如：

分析问题
→ 检索
→ 调工具
→ 判断结果
→ 再调用
→ 输出

---

3. Memory

只理解：

短时记忆

会话上下文。

一般：

Redis

message history

---

长时记忆

用户历史 / 向量检索。

一般：

RAG

vector db

---

4. SSE

理解：

为什么 AI 产品喜欢流式输出

重点：

用户体验

token streaming
