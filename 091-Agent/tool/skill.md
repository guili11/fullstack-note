### Skill

#### 解决什么问题？

单个 Tool 只能完成单一动作，而真实业务任务通常需要多个 Tool、Prompt、Memory、RAG 等能力协同完成，导致能力碎片化、复用困难。

举一个例子：
 一个 帮助人 规划 出国旅游的skill，需要具备查看天气tool，查看航班tool，更加自动还得 具备 订阅航班的tool

---

#### 怎么解决的？

将 Prompt、Workflow、Tool、Memory、RAG 等能力按特定任务进行组合和封装，对外提供一个完整、可复用的任务能力（Skill）。

例如：

```text
Redis复习 Skill
├── 搜索知识库
├── 搜索用户记忆
├── 分析薄弱点
└── 生成练习题
```

用户只需调用 Skill，而无需关心内部调用了哪些 Tool。

---

#### 未来可能有什么问题？

随着 Skill 数量增加，会出现：

```text
Skill 如何发现？
Skill 如何选择？
Skill 如何组合？
Skill 如何管理？
```

问题逐渐从 Tool 编排演化为 Skill 编排。

---

**一句话总结：**

```text
Skill 解决能力碎片化问题，通过组合和封装多个能力形成可复用的任务能力；进一步的发展问题则是 Skill 的发现、选择与编排。
```
