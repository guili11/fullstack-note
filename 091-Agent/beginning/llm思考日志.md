# 有无真值 以及 概率空间情况？
4. 这两个维度的组合才是真正关键

我帮你做个 2×2：

🧩 ① 有真值 + 高集中（最理想工程状态）
RAG + 工具调用 + 明确结构

例子：

SQL查询
代码生成（带约束）
检索问答

👉 最稳定

🧩 ② 有真值 + 低集中（危险）
信息对，但模型没收敛

例子：

数学推导
多步计算
长链逻辑

👉 容易错步骤

🧩 ③ 无真值 + 高集中（看起来很好）
语言风格稳定，但可能是“编得很像真的”

例子：

自信的解释
很流畅的总结
错误但一致的故事

👉 幻觉最危险形态

🧩 ④ 无真值 + 低集中（发散）
创意输出 / brainstorming

例子：

创意写作
idea生成
