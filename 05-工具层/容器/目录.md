# Docker & Nginx & Docker Compose 复习目录

## 1. Docker 基础
### 1.1 容器与镜像
- 容器 vs 镜像
- 容器生命周期：create → start → stop → restart → rm
- 镜像构建和管理命令
  - `docker build`
  - `docker pull`
  - `docker images`
  - `docker rmi`

### 1.2 Docker 常用命令
- 容器管理：
  - `docker ps`, `docker ps -a`, `docker exec -it`, `docker logs`
- 镜像管理：
  - `docker build`, `docker tag`, `docker push`
- 网络管理：
  - `docker network ls`, `docker network create`, `docker network inspect`
- 数据卷管理：
  - `docker volume ls`, `docker volume create`, `docker volume inspect`

### 1.3 Docker 网络与存储
- 网络模式：
  - bridge, host, overlay, none
- 数据卷 vs 绑定挂载
- 持久化数据策略
