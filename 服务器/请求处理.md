Request Line (请求处理链路)
├─ Layer 1: Transport (协议接入)
│  ├─ ⭐ 协议解析 (HTTP/gRPC) - 处理二进制流并反序列化为逻辑结构体
│  ├─ ⭐ TLS/SSL (Security) - 处理加密证书握手与安全通信边界
│  └─ 🚀 协议升级 (WebSocket) - 从无状态请求到持久化长连接的状态转换
├─ Layer 2: Control & Gateway (安全与流量控制)
│  ├─ ⭐ 统一身份认证 (Auth) - 解析 JWT 或 Session 确认请求发起者身份
│  ├─ ⭐ 权限控制 (RBAC) - 检查该用户是否有权对该资源进行特定动作
│  ├─ 🚀 流量控制 (Rate Limit) - 基于令牌桶/漏桶算法防止突发流量压垮系统
│  └─ 🚀 熔断降级 (Breaker) - 自动检测下游波动并决定是否开启故障保护
├─ Layer 3: Middleware Pipeline (横向逻辑切面)
│  ├─ ⭐ 链路追踪 (Tracing) - 提取 Header 中的 TraceID 并延续 Span 记录
│  ├─ ⭐ 异常捕获 (Recover) - 拦截 Handler 内部的 Panic 防止整个服务崩溃
│  └─ 🚀 监控采样 (Metrics) - 记录每个路由的 QPS/Latency/Error 关键指标
├─ Layer 4: Business Logic (业务核心)
│  ├─ ⭐ 参数校验 (Binding) - 验证输入的业务字段是否符合逻辑约束
│  ├─ ⭐ 上下文传递 (Context) - 负责请求级超时控制与跨函数元数据传递
│  ├─ ⭐ 对等服务调用 (RPC Call) - 协同其他微服务完成复杂业务闭环
│  └─ 🚀 并发模型 (Concurrency) - 正确使用 WaitGroup/Channel 处理并行逻辑
├─ Layer 5: Data Persistence (存储交互)
│  ├─ ⭐ 事务管理 (Transaction) - 保证多个存储操作的 ACID 原子性
│  ├─ ⭐ 缓存策略 (Caching) - 处理缓存一致性与穿透/雪崩等边缘场景
│  └─ 🚀 消息投递 (Event/MQ) - 对于非强一致性业务进行异步解耦与通知
└─ Layer 6: Egress (响应与出口)
   ├─ ⭐ 统一错误码 (Error Mapping) - 将内部错误转换为外部友好的 HTTP/GRPC 码
   ├─ ⭐ 数据塑形 (Response DTO) - 只返回客户端需要的字段，过滤敏感信息
   └─ 🚀 响应压缩 (Compression) - 根据客户端 Header 进行数据压缩以节省网络带宽
